# v0.3.29

跨零点不再翻页——熬夜聊到 0 点后的事，嘴里还是「今晚」，不会变成「昨晚」。

## 现象

前一夜 23:50 的亲密互动，到凌晨 1 点生成回复建议时，材料里写成「昨天 23:50」，建议跟着写「昨晚那次」，她也就照说「昨晚」。

可人还没睡，那件事在心里就是今晚。

## 根因

`core/guidance.py` 的 `relative_when` 只看日历日期差：

```python
days = (now.date() - moment.date()).days
if days == 1:
    prefix = "昨天"
```

零点一过，「今晚」立刻变「昨天」，不关心人睡没睡。

## 改动

1. **`relative_when`（core/guidance.py）**

   新增 `NIGHT_CUTOFF_HOUR = 5`、`NIGHT_CARRYOVER_HOURS = 8.0`：
   当前仍在凌晨（< 5 点）且事件发生在 8 小时内时，标签统一用「今晚」；
   超出范围仍走原日期逻辑（今天 / 昨天 / N天前 / 月日）。

2. **边界对齐**

   5 点这个界与 `core/attention.py` 的凌晨语感（`0 <= anchor.hour < 5`）一致，
   避免待关注事项与回复建议一个算今天、一个算昨天。

3. **提示词补一条**

   guidance 生成规则增加：材料里写「今晚」的事就是今晚，熬夜还没睡、跨了零点也算今晚，
   照说今晚，不许改口成「昨晚」。

   材料写对之后再加一道，防模型自己改口。

## 测试

新增 `tests/test_relative_when_night.py` 6 例：跨零点 2 小时、刚过零点、昨日白天超 8 小时、
白天不归今晚、多日计数、ISO 字符串输入。

全量 **197 passed**。
