# v0.3.34

她有生理期了；空清单也不再声明「没有」。

## 一、生理期（按角色存一个开始日，其余现算）

新增 `core/cycle.py`（纯函数，110 行）：

- `phase_of(today, settings)` → (阶段, 第几天)：经期 / 经后 / 排卵期 / 经前；
- `body_line()` → 对话注入用的一句体感，非经期返回空串；
- `schedule_hint()` → 给忙碌管理的日程生成用，档位由对方决定；
- 未配置开始日、开始日在未来、日期解析失败，一律返回 `None`，整套静默。

注入位置在**身体反应档位之前**（先说身体怎么样，再说因此怎么反应）：

```
当前心境：平静
经期第2天，小腹坠着，腰有点酸，人没什么劲
当前身体反应档位：平静。身体平静，没有明显性反应。……
```

**刻意不做的**：

- 不进 `ledger.events`（它不是一件事）、不进 `attention_items`（不是待办）；
- 不做「今天说过没」的标记——那要检测她说了什么，会说错；只按日期现算；
- 不做情绪结算的系数偏移：先在表达层跑一段时间，看是不是真需要动数值。

数据文件 `data/plugin_data/astrbot_plugin_emotion_state/cycle.json`，**按角色分键**（生理期属于角色，不属于某个聊天对象，否则同一天对两个人会是两个第几天）。原子写，读失败一律当没配置。

指令：`/生理期`（看状态）｜`/生理期 开始 2026-11-03`（设置）。仅私聊生效。开关与周期长度在配置页。

开始日**允许提前 7 天**（「明天开始」「下周一」都是真实需求），超过 7 天视为手抖，拦住。提前设置期间不注入、不影响日程，面板显示 `尚未开始（1 天后生效）`，不写成「异常」——用户没做错任何事。

参数从**消息原文**里剥命令前缀取，不走宿主的形参分配：宿主按空格逐个分配，handler 只有两个形参时 `/生理期 开始 2026-11-06` 的日期会被当成多余参数丢掉（真机故障：回「日期看不懂」）。`GreedyStr` 注解在这里也不可用——`from __future__ import annotations` 会让注解变成字符串，宿主认不出来。

对外新增回调 `_emotion_state_cycle_context(umo, target_date, level)`，只给忙碌管理用，不进 `_live_context`（那是低敏感公共接口，生理期不该泄漏给所有读它的插件）。

## 二、空清单不再注入占位句

`build_snapshot` 里这两句删了：

> 当前没有足够确定、需要特别带入的具体事情。
>
> 当前没有仍需留意或接续的事项。

判据：**清单类段落空了就不出现，状态类段落必须有值**。清单清空不是信息，说「没有待办」反而在提醒模型「待办」这个类别存在，它会去填补。

`build_live_schedule_context`（给日程修正的低敏接口）本来就没有占位句，本次不动。

## 三、面板加一行

状态卡片在「身体反应」下面多一行「生理期」：

- 未配置：`未配置（/生理期 开始 YYYY-MM-DD）`——给的是能直接照抄的动作，不是一个空值；
- 已配置：`经期第 2 天 · 距下次约 27 天`；
- 开始日异常：`开始日异常，暂不生效`。

只加这一行，不做独立页面、不做图表：它只有一个变量（第几天），多画一层反而更难读。

`/情绪管理 查看` 的图片同步：在「身体反应」卡片里，生理期那句跟在档位词（平静/轻微/明显/强烈）**右边同一行**，15px 粉色。

**不另起一行**：卡片第三行原本是留白（呼吸位），塞字会把卡片压得很挤——第一版就是这么写的，实际出图明显发闷。挤在档位词右边则正好用上那块空位；档位词固定两字，右侧到胶囊之间还有两百多像素，最长那句「经前第 25 天 · 距下次约 4 天」也撞不到。未配置、经后期、排卵期时这句话不出现，卡片完全不变。

## 四、「没有事项被注入」现在会说为什么

面板上半部写「此刻没有待关注事项被注入提示词」，下半部却列着一条——看起来像 bug，其实是那条**没通过筛选**（最常见的是 `proposed`：她在猜，不是你明说的）。

现在空状态带上原因汇总：

> 此刻没有待关注事项被注入提示词（1 条待双方确认，不算约定）

原因只有这几种，都来自 `select_attention_items` 的同一条判据：待双方确认 / 不是明说的约定 / 短期状态 / 证据不足 / 被条数上限挤掉 / 已终结。判定仍在原处，新加的 `attention_exclusion_reason` 只负责把「被哪一条挡了」翻译成人话——两处各写一套判据，迟早漂移。

**没有放宽注入条件**：`proposed` 依然不进注入。把「她猜的」当既成约定递进去，模型会理直气壮地说「你答应过我」。
