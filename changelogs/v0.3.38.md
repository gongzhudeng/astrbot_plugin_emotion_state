# v0.3.38

日期校准补齐 `update` 分支。

## 上一版漏了一半

v0.3.37 只在 `create` 时校准，但 `update` 也会改 `due_at`：

```python
current.due_at = normalize_due_at(
    observation.due_at or current.due_at or resolve_due_at(current.time_hint)
)
```

模型在「改到星期天」这种 update 里同样会给错日期，这条路径没走校准，等于把洞堵了一半。

现在两条路径共用 `reconcile_due_at`：日期信本地日历、钟点信模型。
