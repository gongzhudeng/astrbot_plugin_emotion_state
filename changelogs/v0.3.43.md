# v0.3.43

v0.3.42 自查补两处。

## 一、面板说的原因不对

`should_inject` 加了「提醒后 30 分钟静默」，但 `attention_exclusion_reason`
没跟着改：面板会把这种情况显示成「还未到时间」，看起来像窗口算错了。

现在两处共用一个判定：

```python
_reminder_silence_active(item, now)
```

面板文案改成「刚提醒过，暂时不重复」。

## 二、标记提醒会让复核失败

`mark_reminded` 原本把 `version` 加 1。但 `version` 是对外的乐观锁：
复核拿着生成时的 `item_version` 回来，会撞上 `stale_item_version` 被拒——
「标记提醒」这种内部记账不该让别人的完成判定失败。

改成一概不动 `version`。写盘仍能检测到变化（比较的是 `to_dict`）。

## 测试

`test_mark_reminded_records_without_touching_status` 的断言同步为版本号不变。
