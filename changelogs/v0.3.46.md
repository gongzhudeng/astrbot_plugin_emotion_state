# v0.3.46

睡前跨天，整点浮动。

## 一、「睡前」= 次日 00:30

原来「睡前」和「夜里」一起落到当天 23:59，等于提前一个半小时叫人。

现在拆开：

```
anchor 22:00 说「睡前」    → 次日 00:30
说「明天睡前」             → 后天 00:30（明天夜里跨零点）
「晚上/夜里」不动          → 当天 23:59
```

`day_offsets` 里的「明天睡前」也跟着改，否则会停在明天 23:59，差一天。

## 二、整点提醒加随机分钟

人不会正好在 15:00:00 想到要提醒你。

新配置 `attention_due_jitter_minutes`（默认 10）：due 落在**整点或半点**时，往后随机 1~10 分钟。

```
15:00 → 15:06
15:00 → 15:09
15:00 → 15:03
```

三条约束：

- **只动整点和半点**：15:07 这种已经是人给的时间，再挪会越滚越偏
- **只往后**：往前挪等于提前，跟「不提前打扰」的原则冲突
- **不跨天**：23:30 + 10 分钟要卡住，不能滑到第二天

改在**建项时**而不是发送时：这样注入窗口、主动提醒、面板显示全链路一致，
不会出现「显示 15:00，实际 15:07 才说」的割裂。

## 配置

| 项 | 默认 | 说明 |
|---|---|---|
| `attention_due_jitter_minutes` | 10 | 滑杆 0–30，0 = 不浮动 |
